# Overhead figure parameters

Search settings and per-ε schedules for the `overhead` search. README.md maps each search to the paper figure it feeds.

## Settings

| Parameter | Value |
| --- | --- |
| script | plotting/plot_overhead.py |
| step_mode | plane_wave |
| λ-mode | lemma57_fixed |
| orders (p) | 1, 2, 4 |
| ε grid | 50 points, log10 in [-6, -0.0457575] |
| q_min, q_max | 1, 10 |
| ‖b‖₁² search cap | 100 |
| brute permutations | False |
| drop p=1 points with ‖b‖₁² > | 1000 |
| system size n (λ-comm) | 1 (overhead omits the explicit n prefactor) |
