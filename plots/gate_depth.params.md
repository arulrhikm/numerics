# Gate-depth figure parameters

Search settings and per-ε schedules for the `gate_depth` search. README.md maps each search to the paper figure it feeds.

## Settings

| Parameter | Value |
| --- | --- |
| script | plotting/plot_gate_depth.py |
| step_mode | gate_depth |
| λ-mode | lemma57_fixed |
| orders (p) searched | 1, 2, 4 |
| ε grid | 50 points, log10 in [-6, -0.0457575] |
| q_min, q_max | 1, 10 |
| ‖b‖₁² search cap | 10 |
| brute permutations | False |
| system size n (λ-comm) | 100 |

## Additional curves

- **Trotter p = 6 (analytic, no Richardson)**: closed form C_p^(1+1/p) · ε^(-1/p) · (2/(1+p))^(1/p) with C_6 = 50
- **envelope (right panel)**: Best Trotter taken over p ∈ {1, 2, 4, 6}; Best extrapolated taken over p ∈ {1, 2, 4} and both schedules.
